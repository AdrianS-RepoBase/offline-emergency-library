Offline Dictionary (Deutsch ⇄ English)

The kit's manuals are mostly English; the offline AIs can translate, but a dictionary is more reliable for single words, medical/technical terms and spelling (small models invent words and make mistakes). Use the dictionary for words and the AI for whole sentences — and double-check anything safety-critical.

What's included

Folder: Deutschland\Woerterbuch\ (Kiwix .zim files)

File Use for
wiktionary_de_all_*.zim German Wiktionary — German words, grammar, translations into English and many languages
wiktionary_en_all_*.zim English Wiktionary — English words, definitions, German translations

How to use

  1. Open Kiwix (Kiwix-Reader\) → Open file → choose a wiktionary_*.zim.
  2. Type the word in the search box.
    • German → English: search the German word in the de archive (look for the Übersetzungen / "Translations" block) or in the en archive (it also has German entries).
    • English → German: search the English word in the en archive and open the Translations → German list; or in the de archive, search the German equivalent.
  3. For medical/technical terms, also search WikiMed (Medical\) in English, then open the language link or search the German name in the German Wikipedia ZIM.

Tips

  • Use the dictionary for medicine dosages, tool names, chemicals — not the AI.
  • Search the basic form (infinitive, singular): gehen, not ging.
  • German compound words: split them (Rettungsdecke = Rettung + Decke).
  • On the phone: Kiwix Android app opens the same .zim files.
